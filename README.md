
Gentle Steps
Specialized Digital Mental Health & Care Pathways

Gentle Steps is a grief-focused telehealth platform connecting people with licensed therapists who specialize in loss of a loved one, substance use recovery, and childhood trauma. This repository contains the front-end marketing website, built as a static, responsive, multi-page experience.


About
Gentle Steps exists so that grief, recovery, and healing never have to be carried alone. The site is designed with a warm, playful, neo-brutalist aesthetic that makes mental health care feel less clinical and more human.

The platform focuses on three core pathways:

Grief & Loss Care — structured, gentle guidance through bereavement and processing loss.

Substance Recovery — a non-judgmental telehealth space for drug abuse recovery and healing habits.

Childhood Trauma — reparenting, healing inner child wounds, and building safety in relationships.

Features
Fully responsive layout (mobile, tablet, desktop)

Neo-brutalist design with bold borders, offset shadows, and playful colors

Custom Tailwind CSS configuration via CDN

Lucide icon set

Google Fonts: Fredoka (display) & Plus Jakarta Sans (body)

Sticky navigation with mobile menu

Matching wizard modal for specialist intake

Scroll-reveal animations (respects prefers-reduced-motion)

Accessible focus states

Marquee band, floating stickers, and hover micro-interactions

Multi-page structure: Home and About Us
